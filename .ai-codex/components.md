# Component Index — SecVault

Dense lookup table of every React component under `components/**`. `(c)` prefix = client component
(`'use client'`). No prefix = server component. Format: `(c) Name  prop1, prop2 — purpose`.
Generated by reading every file directly; not hand-maintained prose — re-generate if this drifts.

## icons.js
